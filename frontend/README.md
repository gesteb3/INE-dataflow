# Frontend

Interfaz Angular de INE DataFlow para cargar encuestas, revisar la calidad de los datos y confirmar lotes.

## Ejecución local

```bash
npm install
npm start
```

Abrir `http://localhost:4200`.

La aplicación consume la API en `http://localhost:8001`.

## Ejecución con Docker Compose

Desde la raíz del repositorio:

```bash
docker compose up --build
```

Abrir `http://localhost:4200`.
